# Interactive Dashboard Development

## Project Overview
This project is an interactive Business Analytics Dashboard developed using Python and Streamlit.

It helps users analyze business sales data through interactive charts, filters, and performance indicators.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Features
1. Interactive dashboard.
2. Region-wise filtering.
3. Department-wise filtering.
4. Product-wise filtering.
5. Total revenue analysis.
6. Total profit analysis.
7. Total orders analysis.
8. Monthly revenue visualization.
9. Regional performance analysis.
10. Department performance analysis.
11. Filtered data display and CSV download.

## How to Run

1. Install Python.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```

4. Open the displayed localhost address in your browser.

## Dataset
The project uses an illustrative business sales dataset containing date, region, department, product, sales, profit, and orders.

## Conclusion
This project demonstrates how interactive dashboards can help users understand business performance and make data-driven decisions.
